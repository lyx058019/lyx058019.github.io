### 1.2 联盟链接插入策略

#### 插入位置规范（不影响阅读体验）

**1. 文章顶部「工具推荐」横幅（非侵入式）**
```
位置: 文章 H2 标题下方，文章导读区
形式: 单行横向卡片，浅灰背景，左图右文
示例: "💡 本篇文章用到的工具：Cursor（AI编程）、Notion（知识管理）"
样式: 背景 var(--el-fill-color-light)，字号 14px，不遮挡正文
```

**2. 文章正文「工具介绍」段落内**
```
位置: 首次提及某工具的功能描述时
形式: 工具名加粗 + 超链接（带 UTM）+ 可选小图标
示例: 「我用 [Cursor](链接) 来处理前端代码，它的 AI 补全比 GitHub Copilot 更懂我的项目上下文」
样式: 链接使用主题色，不使用 Button 样式，保持文字流自然
```

**3. 文章末尾「相关工具」卡片组**
```
位置: 正文结束后，相关文章推荐前
形式: 2x2 网格工具卡片，含图标、名称、一句话描述、CTA按钮
示例: [Cursor] [Notion] / [ChatGPT] [Midjourney]
样式: 白色卡片+阴影，CTA按钮使用主色调
```

**4. 工具箱页面工具详情区**
```
位置: 每个工具图标的悬停弹窗或详情区
形式: 工具简介 + 「官网」链接（带联盟参数）+ 「免费/付费」标签
```

#### 禁止的插入方式
- 弹窗广告 / 遮罩式广告
- 文中硬植入与内容无关的工具
- 大量重复链接（同一工具最多出现 3 次）
- 欺骗性下载按钮

### 1.3 UTM 参数配置方案

统一使用以下 UTM 结构，便于在 Google Analytics 中区分流量来源：

```
https://cursor.sh/xxx?ref=micrabbit&utm_source=micrabbit&utm_medium=affiliate&utm_campaign={campaign}&utm_content={content}

参数说明:
├── utm_source: 固定 "micrabbit"（来源网站）
├── utm_medium: "affiliate"（媒介类型）
├── utm_campaign: 工具名_文章主题（例: cursor_ai团队, notion_工作流）
└── utm_content: 内容位置（例: header-banner, in-article, footer-card）
```

**Campaign 命名规则**:

| 文章 | Campaign 值 |
|------|------------|
| AI团队搭建指南 | `cursor_ai-team`, `claude_ai-team`, `notion_ai-team` |
| 前端AI工具对比 | `cursor_fe-compare`, `copilot_fe-compare` |
| 小红书内容工作流 | `notion_xiaohongshu`, `chatgpt_xiaohongshu` |
| 一人公司效率工具 | `cursor_one-person`, `notion_one-person`, `figma_one-person` |

**链接管理**: 使用 bit.ly 或自建短链服务（`lyx.li/cursor`）压缩联盟链接，美化 URL 的同时保留 UTM 参数。

## 三、工具箱变现方案

### 3.1 免费 vs 付费功能划分

| 功能点 | 免费版 | 付费版（Pro，29元/月） |
|-------|--------|----------------------|
| URL编解码 | ✅ 基础功能 | ✅ 批量处理（一次100条） |
| Hash计算 | ✅ MD5/SHA1 | ✅ SHA256+盐值+批量 |
| 颜色转换 | ✅ 单个颜色 | ✅ 调色板生成+导出 |
| 二维码生成 | ✅ 基础二维码 | ✅ Logo嵌入+样式定制+批量 |
| 时间戳转换 | ✅ 单个 | ✅ 批量+时区对照表 |
| JSON格式化 | ✅ 基础美化 | ✅ 差异对比+JSON→TypeScript类型 |
| 图片处理 | ✅ 基础压缩 | ✅ 批量压缩+格式转换+水印 |
| 历史记录 | ❌ 无 | ✅ 最近100条记录 |
| 导出功能 | 手动复制 | 一键复制+下载 |

### 3.2 付费功能设计（5 个核心点）

**1. 批量处理（高需求）**
- 痛点：用户处理多条数据时需要重复操作
- 功能：URL批量编解码（最多100条同时）、Hash批量计算
- 定价：包含在 Pro 套餐中

**2. 二维码样式定制（中需求）**
- 痛点：品牌方需要带Logo和品牌色的二维码
- 功能：Logo嵌入、颜色定制、圆角/直角、批量生成
- 定价：包含在 Pro 套餐中

**3. JSON 深度处理（程序员刚需）**
- 痛点：前端工程师经常需要 JSON→TypeScript 类型转换
- 功能：JSON与TypeScript类型互转、JSON差异对比（Diff）、数据抽样
- 定价：包含在 Pro 套餐中

**4. 图片批量处理（设计师需求）**
- 痛点：需要处理大量截图/配图
- 功能：批量压缩（支持WebP/AVIF）、批量加水印、格式转换
- 定价：包含在 Pro 套餐中

**5. 历史记录与云同步（提升留存）**
- 痛点：工具使用记录无法追溯
- 功能：最近100条操作记录、支持导出为文件
- 定价：包含在 Pro 套餐中
