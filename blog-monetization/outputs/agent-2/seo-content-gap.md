## 四、技术SEO 修复建议（按影响力排序）

### Top 1：图片优化（T1 + T4 + T6 + S6）— 影响最大

**问题：** 当前图片无 WebP 格式、无懒加载、无宽高属性，影响 Largest Contentful Paint 和 CLS 两项 Core Web Vitals 核心指标。

**修复步骤：**
1. 安装 `sharp` 或 `vite-plugin-imagemin`
2. 构建时自动将所有图片转为 WebP，压缩率 >70%
3. 非首屏 `<img>` 添加 `loading="lazy"` 和 `width`/`height` 属性
4. 验证：Lighthouse Performance > 90

**影响力：** ⭐⭐⭐⭐⭐（直接关联 Core Web Vitals，Google 排名因子）

---

### Top 2：Canonical URL 检查（I4）— 高优先级

**问题：** 静态站点易产生重复内容（带/不带trailing slash、不同路径访问同一内容）。

**修复步骤：**
1. 使用 `vite-plugin-canonical` 或手动在 head.ts 中注入 `<link rel="canonical">`
2. 确保每个路由的 canonical 指向规范 URL
3. 验证：Google Search Console 无"已检测到链接属性问题"

**影响力：** ⭐⭐⭐⭐（防止权重分散，确保页面排名归一）

---

### Top 3：移动端体验全检（M1-M5）— 高影响力

**问题：** 移动端流量占比持续增长，Google 移动优先索引要求页面完全适配。

**修复步骤：**
1. 使用 Chrome DevTools 设备模式测试 320px / 375px / 768px 断点
2. Lighthouse Mobile 评分达到 90+
3. 重点检查：字体可读性、点击目标间距、无 hover-only 交互
4. 汉堡菜单键盘可访问性

**影响力：** ⭐⭐⭐⭐（Google 移动优先索引，移动体验直接影响排名）

---

### Top 4：JSON-LD 结构化数据完善（S4 + S5）— 中高影响力

**问题：** 已有 Article/WebSite schema，但缺少面包屑和 FAQ，错过富媒体展示机会。

**修复步骤：**
1. 在 `src/seo/head.ts` 中为文章页添加 BreadcrumbList
2. 长文（>1500字）添加 FAQPage schema
3. 使用 [Schema Markup Validator](https://validator.schema.org/) 验证
4. 验证：Google Search Console 结构化数据报告无错误

**影响力：** ⭐⭐⭐（增强 Google 理解，直接提升点击率；实现成本低）

---

### Top 5：站点地图与索引管理（I2 + I4）— 中影响力

**问题：** sitemap 状态"待检查"，需确认 URL 完整性和 robots.txt 配置。

**修复步骤：**
1. 确认 `public/sitemap.xml` 包含所有文章 URL（含 lastmod）
2. 手动提交 sitemap 到 Google Search Console
3. 检查 robots.txt 确保未意外禁止抓取
4. 定期检查 404 链接，建立死链重定向流程

**影响力：** ⭐⭐⭐（确保 Google 正确抓取和索引全部内容）
