# lyx058019.github.io

这是一个基于 **Vue 3 + Element Plus + Vite** 开发的个人静态网站，托管于 GitHub Pages。

## 快速开始

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run dev
```

### 构建打包

```bash
npm run build
```

## 技术栈

- **框架**: Vue 3.5+ (Composition API / `<script setup>`)
- **构建工具**: Vite 7.3+
- **UI 组件库**: Element Plus 2.13+ (按需引入)
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **编程语言**: TypeScript 5.9
- **文章渲染**: unplugin-vue-markdown + PrismJS

## 自动化部署

项目配置了 GitHub Actions，推送到 `main` 分支后会自动构建并部署到 [https://lyx058019.github.io/](https://lyx058019.github.io/)。
