## CONVENTIONS
- Vue 3 `<script setup>` + TypeScript; path alias `@/*` points to `src/*`.
- Static content belongs in `src/data` (no large hardcoded text in components).
- SCSS only; component styles use `<style scoped lang="scss">`.
- Use Element Plus CSS variables instead of hardcoded colors.
- Dark mode managed via `@vueuse/core` `useDark`.

## ANTI-PATTERNS (THIS PROJECT)
- Hardcoded large content blocks inside Vue components (move to `src/data`).
- Hardcoded color values in component styles (use Element Plus CSS variables).

## UNIQUE STYLES
- Markdown posts compiled to Vue via `unplugin-vue-markdown` with PrismJS highlighting.
- Runtime SEO handled by `applySeoFromRouteMeta` on each route change.
