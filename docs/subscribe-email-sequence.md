# 邮件订阅欢迎序列设计

## 概述

本文档设计 MicRabbit 博客的邮件订阅欢迎序列（Welcome Sequence），用于新订阅用户激活和留存。

---

## 邮件序列架构

```
Day 0 (立即发送)
    ↓
Day 1 (欢迎邮件)
    ↓
Day 2-3 (价值内容)
    ↓
Day 5-7 (互动引导)
    ↓
Day 14 (终极CTA)
```

---

## Day 0：欢迎邮件（立即发送）

**目标**：确认订阅、介绍自己、建立期待

**主题**：
```
欢迎来到 MicRabbit！🎉
```

**内容**：
```
Hi [名字|订阅者]

感谢你订阅 MicRabbit！

我是 MicRabbit，专注 AI 实战、一 人公司和内容运营。

你将收到：

📧 每周一篇深度文章（干货+实战）
🔧 免费工具和工作流模板
💡 AI 创业的一线观察

我的写作原则：
- 不写正确的废话
- 只分享我真正验证过的方法
- 每一篇都对你有用

回复"自我介绍"获取我的背景故事。

-MicRabbit
```

## ConvertKit 自动化配置步骤

### 1. 创建 Sequence

1. 登录 ConvertKit → **Sequences**
2. 点击 **New Sequence**
3. 设置触发条件：**Subscribes to form**
4. 设置发送间隔

### 2. 配置 Sequence 邮件

| 邮件 | 发送时间 | 模板 |
|------|---------|------|
| Day 0 | 立即 | 欢迎邮件 |
| Day 1 | +1 天 | 核心价值 |
| Day 3 | +3 天 | 实战案例 |
| Day 5 | +5 天 | 互动引导 |
| Day 14 | +14 天 | 终极 CTA |

### 3. 设置触发规则

```
触发条件：Form subscribed
触发时机：立即
邮件1：立即发送
邮件2：+1 天后
邮件3：+3 天后
邮件4：+5 天后
邮件5：+14 天后
```

### 4. 添加标签

每个序列添加标签，方便后续分析：
- `sequence:welcome`
- `subscribed:2026`

## 关键指标追踪

| 指标 | 目标值 |
|------|--------|
| 打开率 | > 40% |
| 点击率 | > 5% |
| 回复率 | > 2% |
| 转化咨询率 | > 1% |

---

## 邮件合规要求

1. **退订链接**：每封邮件必须包含
   ```html
   <a href="{{ unsubscribe_url }}">取消订阅</a>
   ```

2. **发送频率**：每周不超过 1-2 封

3. **隐私政策**：在网站底部添加隐私政策页面

4. **GDPR 合规**（如面向欧盟用户）：
   - 明确说明收集的数据用途
   - 提供明确的同意选项
